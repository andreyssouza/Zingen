# Zingen

Zingen é um projeto web desenvolvido com **HTML** e **CSS**, com foco em uma interface responsiva, moderna e visualmente agradável.

- Layout responsivo
- Estrutura organizada em HTML semântico
- Estilização customizada com CSS
- Interface pensada para boa experiência do usuário

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
